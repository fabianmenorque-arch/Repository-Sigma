# SIGMA

Sistema Integral de Gestión de Mantenimiento de Activos.

## Estado

En desarrollo.

Versión actual:

0.1.0-alpha

## Requisitos

Python 3.12

## Instalación

```bash
python -m venv .venv

source .venv/bin/activate

pip install -r requirements.txt
```

Windows

```powershell
.venv\Scripts\activate

pip install -r requirements.txt
```

## Ejecutar

```bash
python main.py
```
