# Ingenio Bella Vista · Sistema de Hojas de Vida de Equipos

Sistema de gestión y consulta de hojas de vida de equipos industriales.

## URL del sistema
**https://fabianmenorque-arch.github.io/Repository-Sigma/equipos/index.html**

## Estructura
```
equipos/
  index.html               ← Índice general con buscador
  BV-GRL-MECANICA-001.html
  BV-TRA-1ERMOLIN-001.html
  ... (204 hojas de vida)
alta_nuevo_equipo.html     ← Alta de nuevos equipos
```

## Cómo subir los archivos a GitHub Pages

1. Ir a https://github.com/fabianmenorque-arch/Repository-Sigma
2. Subir todos los archivos de la carpeta `equipos/` a la carpeta `equipos/` del repositorio
3. Subir `alta_nuevo_equipo.html` a la raíz del repositorio
4. En Settings → Pages → Source: seleccionar `main` branch y `/ (root)`
5. En 2-3 minutos el sitio estará en línea en la URL de arriba
