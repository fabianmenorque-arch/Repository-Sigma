Cómo se arma el código

El código SIGMA se arma automáticamente como BV-SECTOR-TIPO### (ej: BV-CA-B001): 2 letras de Sector (fijas, del desplegable), el tipo de máquina detectado por palabra clave en el nombre (B=Bomba, R=Reductor, CF=Centrífuga, etc.), y un correlativo según cuántos equipos de ese mismo sector+tipo ya existen. Si el nombre no matchea ningún tipo conocido, el código sale como XX### — avisá para sumar esa abreviatura.

Después de registrar el equipo acá, corré generar_equipos.py con el CSV actualizado de la pestaña Equipos para crear su página individual en equipos/.
